What is Base64 Encoding and How Does It Work?

Base64 is a binary-to-text encoding scheme that represents binary data in an ASCII string format by translating it into a radix-64 representation. It is designed to carry data stored in binary formats across channels and protocols that only reliably support text content, such as email (MIME), URLs, HTTP headers, XML, and JSON payloads.

Each Base64 digit represents exactly 6 bits of data. Because three 8-bit bytes equal 24 bits, four 6-bit Base64 characters are used to represent three bytes of original data. Consequently, Base64 increases data size by approximately 33%.

Standard Base64 vs. URL-Safe Base64

Standard Base64 encoding uses the characters A-Z, a-z, 0-9, plus + and /, with = used as padding. However, when Base64 is used inside URL query parameters or filenames, the characters +, /, and = hold special reserved meanings.

  • Standard (RFC 4648 §4): Uses + and / with padding =.
  • URL-Safe (RFC 4648 §5): Replaces + with - (minus) and / with _ (underscore), and omits padding = characters so the string can be directly embedded in query parameters without percent-encoding.
