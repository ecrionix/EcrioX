What is a UUID (Universally Unique Identifier)?

A UUID (Universally Unique Identifier), also known in Microsoft ecosystems as a GUID (Globally Unique Identifier), is a 128-bit label used for identifying information in computer systems. Standardized by RFC 4122, a canonical UUID is represented as 32 hexadecimal digits displayed in five groups separated by hyphens in the pattern 8-4-4-4-12 (for a total of 36 characters including hyphens).

Why Version 4 (Random) UUIDs?

Version 4 UUIDs are generated using pseudo-random or cryptographically strong random numbers. Out of the 128 bits:

  • 6 bits: Reserved for variant and version metadata (the version digit is always 4, e.g., xxxx-4xxx-xxxx).
  • 122 bits: Pure cryptographically secure randomness.

With 122 bits of entropy, the total number of possible UUIDs is 2122 (approximately 5.3 × 1036). The probability of generating a duplicate UUID is so astronomically low that for all practical engineering applications, it can be treated as zero.

Cryptographically Secure Client-Side Randomness

EcrioX generates every UUID using the browser's native crypto.randomUUID() or crypto.getRandomValues() engine. It runs directly on your computer without network transmission, ensuring instant generation and total confidentiality for database primary keys, session tokens, or transaction IDs.

Frequently Asked Questions

UUID (Universally Unique Identifier) is the open IETF standard (RFC 4122). GUID (Globally Unique Identifier) is Microsoft's implementation of the standard. In modern software engineering, the terms are interchangeable.
To have a 50% chance of a single collision, you would need to generate 1 billion UUIDs every second for approximately 85 years. You can safely use these UUIDs as database keys without collision fears.
